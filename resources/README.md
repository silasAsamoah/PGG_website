# Chapter Church resources

This folder stores the visual and downloadable assets used by the website. Keep the folder names and filenames consistent with the references in `index.html` and `styles.css`, or update those references when renaming files.

- `logo/` — church logo files
- `images/` — website photos and background images
- `documents/` — optional public documents such as statements of faith, ministry guides, or event flyers

Use images owned by the church or for which the church has permission. For good performance, resize and compress photos before uploading (WebP or optimized JPG is recommended).
